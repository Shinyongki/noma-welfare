# 산청군 연계처 실데이터 초안 (공개 자료 조사, 2026-09-25)

성격: 설계문서 4장 확보 절차 ①(공개 자료)까지만 거친 목록이다. 시군 확인(②)·현장 검증(③)은 하지 않았으므로 전부 `verified: false`.
용도: `pilot-2f`의 `data/linkage_targets_sancheong.json` 교체용. 응모서 캡처(9/29) 전 반영.

## 클로드코드 지시 사항

1. 아래 JSON을 기존 연계처 파일과 **필드 이름을 대조**한 뒤 교체한다. 이름이 다르면 기존 파일 쪽 이름에 맞춘다. **코드는 고치지 않는다**(데이터 교체만).
2. 종류(category)에 기존 목록에 없는 `생계`가 들어 있다. 종류 필터가 고정 목록이면 `생계`를 추가하는 것만 허용한다. 그 외 화면 변경은 하지 않는다.
3. 출처·확인일은 JSON에 넣지 않는다(스키마 변경 금지). 이 문서의 출처 표로 관리한다.
4. 기존 연계 기록이 가상 연계처 id를 참조하고 있으면, 캡처용 시드 스크립트에서 새 id로 다시 만든다. 기존 가상 5건은 삭제하지 않고 `linkage_targets_sancheong.demo.json`으로 보관한다.
5. 교체 후 확인: 산청군 어르신의 연계하기 서랍에 시군 11건 + 경남 전체 2건 = 13건이 뜬다. 진주시 테스트 어르신에게는 경남 전체 2건만 뜬다.
