### 6A — 연계처 정렬

- 규칙: `data/recommend_rules.json` — `version`, `exclude`, `rules`(종류 6개별 단어). 편집 화면 없음, 파일로 고치고 **서버 재시작**. 계산은 `data/recommend.mjs`(순수 함수).
- `GET /api/case/:id/linkage-targets`: 시군 범위로 먼저 거르고, 각 연계처에 `recommend: { score, matched } | null`을 붙여 점수 순 → 기존 순서(파일 순서 = 시군 → 경남 전체)로 정렬. **거르지 않는다.** `?reportId=`로 대상 보고를 지정할 수 있다.
- **대상 보고 정하는 방식**: ① 연계하기 서랍을 보고 행에서 열었으면 그 보고(`reportId`, 조치 불필요로 닫힌 보고면 무시). ② "보고 없이 연계하기"나 지정이 없으면 **연계(`fromReportId`)로 아직 이어지지 않았고 조치 불필요로 닫히지 않은 보고 중 가장 최근 1건**. 없으면 정렬하지 않는다.
- 점수 = 그 종류에서 보고 원문에 들어 있는 서로 다른 단어 수(부분 일치, 반복은 1번).
- 화면: 점수 있는 연계처에 "보고 내용과 관련 · 관련: 밥, 냉장고". "추천"이라는 말은 쓰지 않는다. 선택·필터·저장은 그대로.
- 기록: 외부 연계 생성 시 `linkage.recommendSnapshot = { rank, score, matched, rulesVersion }`. 서버가 서랍과 같은 계산(같은 시군 범위·근거 보고)으로 다시 구한다. `rank`는 **필터 적용 전 전체 목록 기준** 순위(1부터). 점수 0이면 `score: 0`. 내부 의뢰는 `null`. 화면 표시·집계 없음.
- 규칙 보완(초안 대비): 한글은 음절 단위로 맞춰서 "어지러"가 "어지럽다"에, "아프"가 "아파"에 걸리지 않는다 → 활용형 추가(`어지럽`, `아파`, `아픈`, `외롭`, `추워`, `춥`, `더워`, `덥`). 그 밖에 `기침`(의료), `동행`(돌봄). **v2**(10/15): 의료에 인지 관련 `헷갈`, `기억`, `깜빡`, `잊어`, `잊으`, `치매`, `같은 말`, `길을 잃` 추가 — "같은 말을 여러 번 하시고 날짜를 헷갈려 하세요" → 의료 3건이 위(관련: 헷갈, 같은 말). "병원 예약"이 "약"에 걸려 `exclude`(`예약`, `약속`, `약간`)를 두었다 — 맞추기 전에 이 단어들을 지운다.

### 9 — 어르신 연계 연결도

- 위치: 어르신 서랍, 연계 이력 위 `<details>`(기본 펼침, 접은 상태는 서랍을 다시 그려도 유지). `stitch/case.html`의 `drawLinkMap()`.
- 그림: 보고(최근 3건, 넘으면 "외 N건") → 어르신 → 연계(전부). 보고로 만든 연계는 점선으로 보고와 잇는다(가로: 어르신 상자 위·아래로 우회 / 세로: 오른쪽 여백). 그림에 없는 4번째 이후 보고와 이어진 연계는 점선 없음.
- 상태는 글자 + 모양: 결과 미기록 ○(굵은 테두리) / 접수 ● / 미접수 ⊘ / 수락 대기 ◐(굵은 테두리) / 수락 ● / 반려 ⊘.
- 배치는 화면 폭이 아니라 **그릴 자리 폭**으로 정한다: 560px 이상 가로(PC 서랍 640px), 미만 세로(휴대폰). 창 크기가 바뀌면 다시 그린다.

- 연계 상자를 누르거나 Enter → 연계 이력의 그 행으로 스크롤 + 잠깐 강조. 새 API 없음(기존 케이스 응답으로 그림). `tableHtml()`에 행 속성 인자(`rowAttr`)를 하나 더했다(기존 호출은 그대로).

### 9 보강 — 연계하기 서랍의 연결도 (`cf2c760`)

- 위치: 연계하기 서랍, "근거 보고"와 "연계처" 사이. 어르신 서랍과 **같은 코드**(`linkMapCard()`·`drawLinkMap()`)로 그린다. 두 함수에 보기 설정(`lkView`: 펼침 여부·상자 이동 여부·접힘 상태 저장 위치)과 요약 줄을 넘기는 방식이다.
- **기본 접힘.** 접힌 상태에서는 "현재 연계 N건 · 결과 미기록 N" 한 줄만 보이고, 누르면 펼친다. 결과 미기록은 외부 연계 중 결과가 없는 건 수.
- 접힘 상태는 그 서랍(`args.mapOpen`)에만 둔다 — 연계하기 서랍을 새로 열면 다시 접힌다. 필터를 바꾸거나 연계처를 골라도 펼친 상태는 유지된다(연계처 목록만 다시 그리므로).
- 연계가 없으면 접는 영역 없이 "아직 연계가 없습니다" 한 줄.
- **이 서랍에서는 상자를 눌러도 이동하지 않는다.** 상자에 링크·포커스(`data-goto`, `tabindex`)를 달지 않는다. 연계 이력 표가 이 서랍에 없기 때문이다.
- 어르신 서랍은 그대로다(기본 펼침, 상자 → 연계 이력 행 이동, 접힘 상태 유지). 연계하기 서랍을 닫고 돌아오면 어르신 서랍 설정으로 다시 그린다.

### 바뀐 구조 요약

- 세션이 MemoryStore라 재배포하면 전원 로그아웃된다.
- `data/requests.json`이 git 추적 대상이다. 실데이터 투입 전 해결해야 한다.
- **기관별 열람 범위가 나뉘어 있지 않다.** 케이스에 소속 기관 필드가 없고 두 기관이 같은 서비스로 로그인하므로, 어느 기관으로 들어가도 명부 전체와 어르신 상세를 볼 수 있다. 실데이터 투입 전 해결 과제다(작업 7에서는 손대지 않음).
